🩺 Medisetu – Secure Electronic Health Records (EHR)

Medisetu is a decentralized health record management system built using Ethereum blockchain that allows patients, doctors, and diagnostic centers to securely store, access, and share medical data. It ensures transparency, data integrity, and patient privacy through blockchain smart contracts and decentralized IPFS storage.
